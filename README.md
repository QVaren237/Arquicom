# Arquicom

## Ejemplo Java compatible con IntelliJ IDEA

Este repositorio incluye un proyecto Maven con Java 17 para practicar clases, objetos, constructores y `static`.

### Ejecutar el proyecto

1. Abre IntelliJ IDEA.
2. Selecciona **Open** y elige la carpeta del repositorio.
3. Espera a que IntelliJ cargue el proyecto Maven.
4. Configura un JDK 17 o superior si te lo solicita.
5. Abre `src/main/java/com/arquicom/Main.java`.
6. Pulsa el triángulo verde junto al método `main` y selecciona **Run 'Main.main()'**.

### Archivos principales

- `pom.xml`: configuración del proyecto Maven.
- `src/main/java/com/arquicom/Heroe.java`: clase `Heroe`, con constructor, atributos y método de instancia.
- `src/main/java/com/arquicom/Main.java`: punto de entrada que crea dos héroes y muestra sus datos.

No requiere bibliotecas externas.
